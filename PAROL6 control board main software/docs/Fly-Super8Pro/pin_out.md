### Подробная распиновка платы Mellow Fly Super8 Pro в табличном виде

#### 1. ADC (Аналогово-цифровые преобразователи)
ADC-пины для измерения аналоговых сигналов (0-3.3V, 12-бит разрешение). Используются для сенсоров (температура, напряжение).

| Пин  | Детали пина | Тип/Функции | Напряжение/Ток | Примеры подключения | Советы |
|------|-------------|-------------|-----------------|---------------------|--------|
| adc0 | pf4, -, + | ADC/GPIO | 0-3.3V логика, до 5mA | Потенциометр для уровня, термодатчик NTC | Используй делитель для >3.3V. В коде: analogRead(pf4). |
| adc1 | pf5, -, + | ADC/GPIO | 0-3.3V | Сенсор тока/напряжения | Подходит для мониторинга батареи. |
| adc2 | pf9, -, + | ADC/GPIO | 0-3.3V | Фоторезистор для света | Фильтруй шум конденсатором. |
| adc3 | pf10, -, + | ADC/GPIO | 0-3.3V | Внешний АЦП-расширение | Максимальная частота выборки ~3.6 MSPS. |
| adc4 | pc0, -, + | ADC/GPIO | 0-3.3V | Датчик влажности | Альтернатива: PWM или TIM. |
| adc5 | pc1, -, 5v | ADC/GPIO | 0-3.3V (с 5V питанием) | 5V-сенсор (с делителем) | Идеален для 5V устройств; защити от перегрузки. |

| fan2 | pa2 | PWM/GPIO/TIM | 5-24V | Корпусной фан | Альтернатива: UART или ADC. |
| fan3 | pa3 | PWM/GPIO/TIM | 5-24V | | Частота PWM ~25kHz для тишины. |

#### 4. Accelerometer (Акселерометр)
Разъём для SPI/I2C акселерометра (вибрации, leveling). 7 пинов.

| Пин/Группа | Детали пина | Тип/Функции | Напряжение/Ток | Примеры подключения | Советы |
|------------|-------------|-------------|-----------------|---------------------|--------|
| accelerometr | 5v, gnd, pd0, pd1, pd3, pd4, pd5 | SPI/I2C/GPIO (pd0=MISO/SDA, pd1=MOSI/SCL, pd3=CS, pd4=INT1, pd5=INT2) | 5V, низкий ток | ADXL345 или LIS3DH | В Klipper: [adxl345] spi_bus=spi1. Читай данные для калибровки. |

| Пин/Группа | Детали пина | Тип/Функции | Напряжение/Ток | Примеры подключения | Советы |
|------------|-------------|-------------|-----------------|---------------------|--------|
| bltouch | gnd, 5v, pc6 (signal), gnd, pc3 (servo) | GPIO/PWM (pc6=probe, pc3=servo control) | 5V | BLTouch v3 (probe к pc6, servo к pc3) | В Marlin: #define BLTOUCH. Калибровка Z-offset. |

| st-link | reset, pa14 (SWCLK), pa13 (SWDIO), gnd, 3.3v, 5v | SWD (debug interface) | 3.3V/5V | ST-Link v2 или встроенный | Для загрузки прошивки (PlatformIO stlink). |

#### 10. EXP1 (Расширение 1)
10-пиновый разъём для модулей (экран, WiFi).

- gnd, 5v, pg14 (GPIO), pg13 (GPIO), pc13 (GPIO), pc14 (GPIO), pg8 (GPIO), pb2 (GPIO), pe12 (GPIO), pe13 (GPIO).

**Детали**: Вероятно, для TFT-экранов или расширений. Напряжение: 5V. Советы: Пины — GPIO с возможным SPI/I2C.

#### 11. EXP2 (Расширение 2)
10-пиновый разъём, похож на EXP1.

- gnd, 3.3v/5v (выбор), reset, pg15 (GPIO), pb6 (GPIO), pa7 (SPI MOSI), pb7 (GPIO), pa4 (SPI CS), pa6 (SPI MISO), pa5 (SPI SCK).

**Детали**: С SPI-пинами (pa7, pa6, pa5, pa4). Подходит для SD-карт или дисплеев. Напряжение: 3.3V/5V selectable.

#### 12. CAN (Шина CAN)
5-пиновый разъём для сети (гриппер, расширения).

- canl (pb8, FDCAN_RX), canh (pb9, FDCAN_TX), gnd, 5v, can (возможно, boot или en).

**Детали**: FDCAN1 на STM32. Скорость до 1Mbps. Пример: Подключи CAN-гриппер. В коде: HAL_FDCAN. Советы: Используй twisted pair кабель, терминаторы 120Ω.

#### 13. Step Drivers (Драйверы шаговых моторов)
8 групп для TMC-драйверов (stepper). Каждый: step (импульс), dir (направление), en (включение), cs/uart (SPI/UART для config).

| Драйвер | Step | Dir | En | CS/UART | Детали/Советы |
|---------|------|-----|----|---------|---------------|
| 0 | pe2 (PWM/GPIO) | pc5 (GPIO) | pf11 (GPIO) | pc4 (SPI/UART) | Для оси X. Ток до 3A. Config по SPI. |
| 1 | pe3 | pf13 | pf14 | pf12 | Ось Y. |
| 2 | pe4 | pg0 | pg1 | pf15 | Ось Z. |
| 3 | pe14 | pe8 | pe9 | pe7 | Экструдер 1. |
| 4 | pe15 | pe11 | pf2 | pe10 | Экструдер 2. |
| 5 | pe1 | pf0 | pc15 | pf1 | Доп. ось. |
| 6 | pe0 | pg3 | pg4 | pg2 | |
| 7 | pe6 | pg6 | pg7 | pg5 | |

#### 14. TMC SPI (Интерфейс для TMC-драйверов)
- TMC MOSI: pb5 (SPI MOSI, master out)
- TMC MISO: pb4 (SPI MISO, master in)
- TMC SCK: pb3 (SPI clock)

**Детали**: SPI2 или аналог для config всех 8 драйверов (ток, микрошаги). Скорость ~1-4MHz. Советы: Делай CS low/high для каждого драйвера.

#### 15. Bed (Подогрев стола)
- +, pe5 (MOSFET/PWM для high current).

**Детали**: PWM для контроля температуры стола (до 15A). Напряжение: 12-24V. Пример: Картридж нагрева. Советы: Используй твердотельное реле для безопасности.

#### 16. Screen (Экран)
- pa10 (TX?), pa9 (RX?), gnd, 5v.

**Детали**: Вероятно, UART для TFT-экрана (Serial экран). Напряжение: 5V. Пример: Подключи Nextion или LCD. В коде: HardwareSerial для общения.
