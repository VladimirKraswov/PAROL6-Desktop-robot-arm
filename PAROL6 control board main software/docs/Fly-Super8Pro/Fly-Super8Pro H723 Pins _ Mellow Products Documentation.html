Fly-Super8Pro H723

Мощная плата управления для 3D-принтеров на базе STM32H723 с поддержкой до 8 драйверов шаговых двигателей, CANbus и различных интерфейсов.

Внимание! Все силовые разъемы имеют предохранители. Не превышайте максимальные токи.

  • Сигнал PE5
  • Плюс (+) 24V/12V
